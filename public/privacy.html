개인정보 처리 안내

적용일: 2026년 11월 6일

Finalyze.AI는 Google 로그인으로 이용자를 구분하고, 관심 기업과 선택한 공시 알림을 제공합니다.

저장하는 정보

  • 로그인: Google 고유 식별자를 서비스 전용 키로 변환한 사용자 ID와 로그인 세션 식별자의 해시. 이름·프로필 사진·Google 비밀번호·원본 로그인 토큰은 저장하지 않습니다.
  • 관심 기업: 기업 고유번호·기업명·종목코드·등록 시각.
  • 푸시 알림: 사용자가 허용한 기기의 푸시 구독 주소와 암호 키를 암호화해 저장합니다.
  • 이메일 알림: 이메일 알림에 별도로 동의한 경우에만 수신 주소를 암호화해 저장합니다. 발신 설정이 준비되기 전에는 이메일 알림을 켤 수 없습니다.
  • 알림 발송 기록: 중복 방지와 재시도를 위한 공시 접수번호·채널·전송 상태를 최대 30일 보관합니다.
  • 남용 방지: 서비스용 사용자 ID 또는 IP를 서비스 전용 키로 변환한 값에 연결된 로그인·AI 요청 횟수와 단기 잠금을 공유 저장소에 보관합니다. 원본 IP나 재무분석 본문을 이 카운터에 저장하지 않습니다.

보관과 삭제

로그인 세션은 최대 7일 후 만료됩니다. 만료 세션과 보관 기간이 지난 알림 기록은 정기 작업 시 정리합니다. 관심 기업과 계정 정보는 서비스를 이용하는 동안 보관하며, 계정 메뉴의 ‘계정 및 데이터 삭제’를 누르면 세션·관심 기업·알림 설정을 함께 삭제합니다. 알림을 끄면 해당 수신 주소 또는 구독 정보를 삭제하고 이후 발송을 중단합니다. 이미 푸시 서비스에 전달된 알림은 기기에 도착할 수 있습니다.

남용 방지용 식별값과 요청 횟수는 계정 삭제 이후에도 한도 우회를 막기 위해 마지막 허용 요청 후 최대 2일 이내 자동 삭제됩니다. 로그인 인증 요청은 한 번만 사용할 수 있고, 계정당 활성 로그인 세션은 최대 5개로 제한합니다.

외부 서비스

공유 캐시와 남용 방지용 단기 카운터에는 Upstash Redis를 사용합니다.

로그인 확인에는 Google, 호스팅에는 Vercel, 계정 데이터 저장에는 Neon Postgres를 사용합니다. 푸시를 켠 경우 브라우저의 푸시 서비스(Google·Apple·Mozilla 등)에 구독 정보와 암호화된 알림을 전달합니다. 이메일 알림을 켜면 메일 발송에 사용하는 Google(Gmail) 또는 Resend에 수신 주소와 알림 내용을 전달합니다. 각 사업자의 서버에서 정보가 처리될 수 있습니다.

로그인 유지에 HttpOnly 보안 쿠키를 사용합니다. DART 공시 확인과 알림 발송 과정에서는 LLM을 호출하지 않으며, 사용자가 분석을 요청할 때만 재무·공시 데이터를 AI 분석에 사용합니다.
